Google 推出 Gemini Decisions API：只做判断、不写回答

作者：宝玉（@dotey）· 11/12 06:39 北京时间

Google 在 Gemini API 里上线 Decisions API，配套新模型 gemini-decision-1（走 v1beta 接口）：不生成文字，只对一份输入回答一组问题，题型为是非题、单选题（2–255 个选项）、打分题，每个答案带 0–1 的校准置信度，可设门槛（如高于 0.7 自动执行、低于转人工）。单次请求输入最多 256K Token，支持文字、JSON、图片、音频、视频、PDF，同一输入最多挂 1000 个问题；价格为输入每百万 Token 0.1 美元、输出不收费。Google 称输入在 1.6 万 Token 内端到端延迟 150–250 毫秒。在 Google AI Studio 拿 API Key 即可调用，免费层每分钟 200 次、每天 1 万次（免费层数据会被用于改进产品）；不支持上下文缓存和 Batch API。帖中还对比了 OpenAI 同名产品（一次最多 400 个问题，仅收文字/图片/JSON，支持缓存）。
