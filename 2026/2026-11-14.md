### Rust 1.100.0 发布：`!` 类型稳定，Cargo 支持依赖"冷静期"
*作者：lencx（@lencx_）· 11/13 10:59 北京时间*

`!` 类型正式稳定，可写 `Result<T, !>`，`Infallible` 成为 `!` 的别名；自定义分配器核心 API 稳定（`Vec::new_in`、`Box::new_in`）；新增 DropGuard 用于回滚。Cargo 新增未使用依赖检查（暂不报告未使用的 dev-dependencies），并可在 `.cargo/config.toml` 的 `[registry]` 里设 `global-min-publish-age = "3 days"` 跳过发布不足三天的版本。2015/2018/2021 edition 的 never type fallback 由 `()` 变为 `!`，个别代码可能需调整类型推断；Cargo 中间产物目录布局有变，依赖路径的脚本应改用 JSON 消息。升级命令：`rustup update stable`。
