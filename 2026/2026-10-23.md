### PHP2Shell 后续：Cloudflare 拦截量从几千飙到几百万，OpenAI 出检测技能，Node.js 同时修 10 个漏洞
*作者：小莫（@xiaomovps）· 10/22 12:19 北京时间；Geek（@geekbb）· 10/22 10:58 北京时间；Ron（@RonVonng）· 10/22 21:48 北京时间；Peter Steinberger（@steipete，转推 Cloudflare CEO）· 10/23 00:01 北京时间；Lenny Rachitsky（@lennysan）· 10/23 00:12 北京时间*

PHP 两个免登录远程执行漏洞（PHP2Shell）的细节前一天日报已讲，这里是新进展。受影响的 PHP 版本为 8.5.11、8.4.26、8.3.35、8.2.34 及更早，修复版本是 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35；同一时间 Node.js 一次修复 10 个漏洞（包括 Brotli 解压内存越界、DNS 解析异常、TLS 证书验证问题），修复版本为 22.23.4 / 24.22.1 / 26.12.1，Node 20 已停止官方支持、不会再有补丁。小莫提醒：宝塔、WordPress 用户要查**实际运行**的 PHP 版本，Docker 容器里的 Node 也要单独检查（他发现 Nginx Proxy Manager 容器里还是 Node 20，最后换成了 Caddy），升级前先备份。

OpenAI 发布了开源的 `php2shell-checker`，把检测封装成 Codex 技能：根据网站返回的 PHP 头或本机安装判断版本是否受影响（README 强调它只看声明的版本号，不能代替真正验证）。Cloudflare CEO Matthew Prince 公布的数据：漏洞公开前 10 小时，Cloudflare 网络上已看到几千次利用尝试；公开后 45 分钟涨到几万次，2 小时内几十万次，现在已达几百万次。

花絮：日本首相高市早苗亲自发帖说明自己官网因 PHP 漏洞连夜下线修复，并呼吁站长关注政府的网络安全预警账号 @cyber_forecast；Ron 补充说她 8 年前还在名叫"PHP 研究所"的出版社出过一本漫画版防黑客指南。

### 小众软件安全快讯：HTTP/3"头部手风琴"攻击、Chrome 156 修 353 个漏洞、Linux 内核漏洞被误公开、泄漏的 CA 私钥已被用来破解智能音箱
*作者：小众软件（@appinn）· 10/22 13:57–23:17 北京时间*

- **HTTP/3 Header Accordions**：安全团队 FoxIO 10 月 20 日公开一类拒绝服务攻击，利用 HTTP/3 请求头压缩（QPACK）解码时没限制资源，几百 KB 输入就能换来巨量消耗；测试 Bun 时约 516 KiB 数据就让服务器 CPU 卡在 100%。10 种实现里 7 种有问题，包括 quic-go（Caddy、Traefik 在用）、Cloudflare quiche、lsquic、Bun、aioquic/mitmproxy、hyperium h3 和 Wireshark。
- **Chrome 沙箱逃逸 CVE-2026-113328**：Google 10 月 20 日发布 Chrome 156 桌面稳定版，共修 353 个安全问题；这个漏洞可让特制网页在沙箱外执行代码。请升级到 Windows/macOS 156.0.8078.47/48、Linux 156.0.8078.47 或更高，地址栏输入 `chrome://settings/help` 检查更新并重启；其他 Chromium 浏览器看各家公告。
- **Linux 内核漏洞被误发到公开邮件列表**：据 Phoronix 报道，趋势科技 ZDI 的多个未修复内核漏洞报告出现在公开的 LKML，涉及 SMB Direct、KSMBD（两者可远程执行代码，CVSS 9.0）、skb_zerocopy、VMware 图形驱动、NVMe Target 等，部分尚未修复；Greg Kroah-Hartman 已质疑为何发到公开列表。
- **eMudhra 私钥泄漏后续**：有开发者用泄漏的 CA 私钥给 Yandex 域名签发证书，冒充官方服务器下发配置开启网络 ADB，拿到了 Yandex Station Mini 2 智能音箱的 root 权限。设备预装的是根证书，所以更早生产的设备也可能受影响。

### Pi vs DeepSeek Harness 实测：同一任务 Token 差 18–46 倍，费用只差约一倍
*作者：小莫（@xiaomovps）· 10/22 13:36、16:10、17:23、21:14、22:55 北京时间*

小莫用同样的 DeepSeek V4 Flash（思考强度 High）、同一提示词"用 HTML 做一个骑自行车的鹈鹕"对比两个 Agent 框架：Pi 只跑 3 轮、累计输入约 6.4 万 token；DeepSeek Harness（DSH）跑了 28 轮、含 10 次截图自检，累计输入 114.7 万 token。但 DSH 缓存命中率 98.9%，按相同单价估算约 $0.057，Pi 约 $0.0266，费用只差一倍左右，而 DSH 成品效果更好。他的结论是比较 Harness 要把轮数、缓存命中、耗时和最终效果放在一起看。

他还写了一篇 DSH 从安装到插件的完整教程（DSH 一切皆插件，连 Agent 循环都能替换，目前仍是预览版，不建议交给公司核心资料），并介绍了在 DSH 里接入 OpenCode Go 套餐来降低 API 成本（他称 10 美元可用到 80 美元的 DeepSeek V4 Flash 额度）。另一边，xuanwo 称某第三方部署的 DeepSeek v4.1-flash-1017 推理速度达 400 token/s、缓存命中 99%。
