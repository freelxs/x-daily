### 在手机上管 Coding Agent：HerdrChat、Pi 移动端、pi-web-ui、Paseo、Whip
*作者：小墨同学（@xiaomovps）· 11/07 13:53、17:28 北京时间*

Herdr 是管理多个 Coding Agent 的工具，社区配套的 HerdrChat 已上架 App Store（iPhone/iPad，免费），可查看 Claude Code、Codex、Grok、Antigravity 等的运行状态、历史会话、子 Agent 和执行记录，处理需人工确认的操作、打开完整终端；通过 SSH 直连自己的电脑、不经第三方中转，推荐配 Tailscale。注意它不在手机上跑 Agent，电脑或 VPS 要保持在线。Pi Agent 的移动方案有三类：① 手机 App：iOS 上的「Pi: Local Agent Harness」可在本机跑 Pi、管文件、跑 Shell 和 Skills；Android 有 Pocket Pi（单 APK、内置 Termux 运行时、免 Root，较早期）。② 装 Web 插件：`pi install npm:@kkkiio/pi-web-ui`，重启 Pi 后输入 `/webui` 即可在浏览器看当前会话（远程访问别暴露公网）。③ 第三方管理工具：Herdr、Paseo（iOS/Android/Web 同时管 Pi、Claude Code、Codex）、Whip（专为 Herdr 做的 SSH 移动客户端）。

### HiTw93：用 AI 做「不丑、好用」产品的 11 条清单
*作者：Tw93（@HiTw93）· 11/07 21:31 北京时间*

前提：优先级是「解决问题 > 好用 > 好看」。清单可自己对照，也可整份交给 Agent 审代码库：① 假装不懂技术的普通用户走完主流程，把卡住、没解释、衔接不自然处全修掉；② 文案像母语者说话，参考 Apple/Windows 的措辞；③ 界面已说明的不再加字；④ 数字要说明指代、按单位惯例展示并校验准确；⑤ 只有不可撤销操作才二次确认，别铺大红色；⑥ 每页一个强调色，避开橙色、赤陶色和老后台亮蓝，灰色一律用暖灰，可参考中国传统色；⑦ 一页最多 4 种字号，调好行高字距并满足无障碍对比度；⑧ 少用斜体、等宽（只用于代码/路径/指标）和全大写，同一动作全产品用同一个动词；⑨ 圆角嵌套要同心（内圆角 = 外圆角 − 内边距），默认扁平、不叠阴影、不发光、不用毛玻璃、不做卡片套卡片；⑩ 多语言按最长译文排版，不缩字号、不截断；⑪ 反复调不好就让 Agent 给三个方案挑一个再细化，前后对比图放进一个 PDF 看。最后一条：耐心多轮迭代。

### 让 AI「复盘」：把做对的方法写成规则
*作者：電腦玩物 Esor（@esorhjy）· 11/07 15:13 北京时间*

每次和 AI 一起把事情做好后，多问一句：「请根据我们刚才的讨论与修改，整理出这次有效的做法，以及下次执行时需要注意的规则。」自己确认后，把通用原则放进 ChatGPT 自定义指令，把任务规则放进对应项目设置或 Codex 规则/技能。循环是：第一次一起完成 → 人追问修正 → 人验收 → 让 AI 复盘 → AI 保存规则 → 下次按规则自己完成与验收。不必一开始就建完整规则，边做边沉淀。
