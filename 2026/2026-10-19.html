Matt Pocock 的"今日提示词"：让 agent 写一个 pre-commit 钩子，禁止提交超过 5000 token 的文件（按"字节数 ÷ 4"估算 token），只检查暂存区文件，跳过 lockfile、代码生成文件这类不是 agent 写的东西，并在报错信息里写清楚该怎么拆文件；他称这是给代码库做过最简单也最值的投资，还补充说确定性的规则就该用确定性的方式强制执行。onevcat 则在全局 AGENTS.md 里加了两条：① 用户可能出错，遇到明显错误或决策冲突要毫不留情地指出，"你是同事，不是奴仆"；② 多个相互依赖的 PR 用 gh stack 管理（他说模型们目前还不太爱用它）。

tsc-ts 与 scriptc 是什么关系：TypeScript 编译器绕了一圈回到 TypeScript

作者：lencx（@lencx_）· 10/18 08:51（北京时间）

前一天日报提过 Vercel Labs 的 tsc-ts，lencx 把两个项目讲清楚了：scriptc 把 TypeScript / JavaScript 编译成原生可执行文件或 WebAssembly，程序可脱离 Node.js 运行；tsc-ts 用这套能力把 TypeScript 编译器本身做成原生程序，照常做类型检查、生成 JS 和类型声明。对比：传统 tsc 用 TS 写、以 JS 运行；tsgo 用 Go 写、以原生程序运行；tsc-ts 用 TS 写、也以原生程序运行，官方称比 tsgo 快 2–4 倍。

  • FluxDown：免费开源的多协议下载管理器，对标 IDM（正版 24.95 美元且只有 Windows），支持 HTTP、FTP、BT 磁力、电驴和 HLS / DASH 流媒体；文件分段多线程下载，慢的段会被空闲线程接手，支持断点续传；装浏览器扩展后自动接管下载并嗅探视频；Windows、macOS、Linux、安卓都有安装包，也能装到群晖、威联通等 NAS。README 说明本地下载不用注册账号，但不是零遥测：会匿名统计安装和日活，可用 analytics_enabled 关闭。
  • DrawAI：把 AI 生成图、论文插图或幻灯片截图还原成可编辑的 SVG 和 PPT，文字、形状、局部素材会被拆开，导出用的是 PowerPoint 原生形状；可作为 Claude Code / Codex 技能、本地网页工作台或 CLI 使用，团队还配了论文和评测数据集。
  • Spotifast：Rust 写的第三方 Spotify 客户端，不带浏览器内核，内存 100–250MB、启动不到 1 秒；能浏览和编辑歌单、播客，支持 Spotify Connect 和 Google Cast，有可套 Winamp 2 皮肤的迷你播放器和 MilkDrop 可视化（首次会下载 1 万多套预设）；原帖说适合已有 Spotify 会员的人。

  • Strata：让消费级硬件跑 1250 亿参数的千问模型（Qwen3.8-Flash-Next）：模型由 24576 个小专家组成、每个字只用 10 个，最常用的放显卡、全部放内存，CPU 一起算；作者用 RTX 5070 + 64GB 内存测得每秒 53–94 个 token。在本机提供 OpenAI / Anthropic 兼容接口，数据不出电脑。
  • httpSMS：把一部安卓手机变成短信网关，程序调 HTTP 接口就能发短信，收到的短信也能转发到你的地址；可限速（如每分钟 3 条），支持端到端加密（密钥只在手机上），也能用 Docker 自建。
  • Free English Learning Tools：天津一家英语培训学校开源的 11 个免注册练习网站：雅思 7 个（听力阅读专练同义替换、写作改错和 6 分句改 8 分句、英式口音 AI 口语模考并给中文诊断、唐僧师徒当教练的"写作西游记"），以及剑桥 KET / PET / FCE 绘本词卡。
