### Splash：苹果芯片 Mac 的开源本地推理引擎，称比 llama.cpp 快 4 倍
*作者：GitHubDaily（@GitHub_Daily）· 11/21 15:30 北京时间*

Splash 把模型跑在本机，并可一条命令接入 Claude Code 或 Codex，免按量付 API 费。按原帖数据，同样的 27B 模型和量化权重在 M5 Pro 上每秒 74 token，llama.cpp 为 16。做法是先由小模型猜词、大模型一次核对，加上专为苹果 GPU 写的计算代码，内存自动规划。支持 Qwen3.8-27B、Qwen3.6-35B-A3B 等，能看图、调工具，自带聊天页；需 M3 或更新芯片，24 GB 内存可跑小一点的版本。
