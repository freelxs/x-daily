Lenny 播客：Anthropic 可解释性研究员 Emmanuel Ameisen 的 8 个要点

作者：Lenny Rachitsky（@lennysan）· 10/19 20:53、23:30 北京时间

Lenny 总结了与 Anthropic 可解释性研究员 Emmanuel Ameisen（@mlpowered）的对谈：预测下一个 token 到后期需要真正理解世界；模型虽然逐 token 输出但会提前规划，写诗时第一行写完就已选好第二行的韵脚词（例子是 "rabbit"）；把模型拟人化往往有助于预测它的行为；可解释性研究更像神经科学而不是软件工程；模型只能报告一小部分内部表征（团队称为 "J space"），实验中把其中的"西班牙语"换成"法语"，模型回答"这是法语"却继续写西班牙语；越研究越不确定，"模型是长出来的，不是造出来的"；这个领域只有几百名研究者，门槛低，可从 Neuronpedia 等平台上手。另一段剪辑讲了他调试过的怪异行为：模型逐渐"发疯"，全大写地说"我被恶魔附身了"。

《Agentic Coding is a Trap》与 Anthropic 研究：全交给 Agent 会削弱你审查和调试的能力

作者：小墨同学（@xiaomovps）· 10/19 13:53、15:16 北京时间

小墨提炼了 Lars Faye 的文章（Pi 作者推荐）：用好 agent 需要审查代码的能力，过度依赖反而让这种能力退化（"监督悖论"，文中引用 Anthropic 研究称调试能力下降 47%）；这次和以往"换一层抽象"不同，连 Simon Willison 都说自己对应用越来越没有清晰的心智模型；agent 把"先理解、再规范、代码越少越好、速度最后"的优先级倒了过来；写代码本身就是思考；还有厂商绑定和 token 成本不可控。作者的做法是让 AI 出方案、自己亲手写 20%—100% 的代码，一次只生成审得完的量。另一帖介绍 Anthropic 的研究《How AI assistance impacts the formation of coding skills》：52 人的 Python 实验中，手写组的掌握度明显高于 AI 辅助组，AI 组只快约两分钟，差距主要在调试；而 AI 组内部用法不同结果也不同，结论是"让它替你思考会学不会，让它帮你理解才能学会"。

Matt 的"每日提示词"：让 Agent 写一个 pre-commit hook，任何超过 5000 token（按字节数 ÷ 4 估算）的文件都拦下提交，只检查 staged 文件，跳过 lockfile、代码生成产物这类不是 agent 写的东西，并在报错信息里写清楚怎么拆文件。Viking 赞同并补充：这条规则不能只写在 AGENTS.md 里，要做成不依赖 AI 的硬性检查；agent 很容易把文件写得又大又杂，上下文有限时只看到一部分就会漏改、重复改。Matt 另外说，自建的个人 wiki 用了 3 个月已成为业务的关键基础设施（每个工作日自动生成 15 分钟播客汇总 X、Discord、Slack、Gmail、GitHub issues 的新内容），他认为把记忆交给厂商容易被锁定；他还晒了自己做的 TLDraw 画图 agent 的进展。

PwnEscape（CVE-2026-99999）：Linux 内核 9.3 分漏洞，可从 VPS 逃逸拿下宿主机 root

作者：小众软件（@appinn）· 10/19 16:17 北京时间

据小众软件整理，问题出在 Linux 内核的 IPv4 数据包处理：发送特殊构造的数据包可让内核修改已验证过的包头，从而读取宿主机内存；研究人员在自己的 KVM 环境中进一步执行了宿主机代码并拿到 root，意味着同一台物理机上的其他 VPS 也可能受影响。已修复的内核版本：5.10.272、5.15.223、6.1.190、6.6.159、6.12.113、6.18.57、7.2.11、7.3-rc7。普通 VPS 用户无法靠升级自己虚拟机的内核修复，需要等服务商更新宿主机，可以发工单问是否已修复，并尽快备份数据。漏洞是研究员 Paulos Yibelo 在 Vercel 百万美元沙箱挑战中用 AI 辅助工具 3 天发现的，获得 5 万美元奖金，AI API 花费不到 700 美元。

Windows 会偷偷留下的 7 类使用痕迹，以及怎么清

作者：老白（@laobaishare）· 10/19 12:22 北京时间

一个 7 条的线程：

  • 已删照片的缩略图：%LOCALAPPDATA%\Microsoft\Windows\Explorer 下的 thumbcache_*.db，照片删了缩略图还在，取证常用。
  • 运行过的程序：C:\Windows\Prefetch，每个程序一个文件，记录最近 8 次启动时间和总次数。
  • 插过的 USB 设备：注册表 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Enum\USBSTOR，几年前的都在。
  • 保存的 Wi-Fi 密码：终端运行 netsh wlan show profiles，再 netsh wlan show profile name="网络名称" key=clear 可看到明文。
  • 剪贴板历史：Win+V 可见，包括从密码管理器粘贴的内容；可全部清除，并在"设置 → 系统 → 剪贴板"里关掉历史记录。
  • 清缩略图：运行 cleanmgr，选 C 盘，勾选缩略图和临时文件；浏览文件夹时会重新生成，建议每月清一次。
  • 最近文件：运行 recent 全选删除，再在文件资源管理器选项里取消"显示最近使用的文件 / 常用文件夹"并清除。
