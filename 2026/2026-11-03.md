### Claude API 公测「消息线程」：长对话不用每轮重发历史，首字等待缩短约 35%
*作者：宝玉（@dotey）· 11/03 03:34 北京时间*

Anthropic 给 Messages API 上线 message threads 公测：服务器把对话暂存几分钟，下一轮只发新消息和上一条回复的 ID。官方数据：50 万到 100 万 token 的请求，首字等待时间（中位数）缩短约 35%；长对话里单次请求大小（中位数）从约 800 KB 降到 1.8 KB；Claude Code 已对大多数用户默认开启。计费和速率限制不变——省的是上传，不是 token（Claude 每轮仍读完整对话），想省钱还得自己设提示词缓存断点。用法：请求里加 thread 参数和 beta 请求头 `message-threads-2026-08-12`；线程 5 分钟无请求就过期（返回 404），本地仍要留完整记录重建；中途不能改系统提示词、工具、模型和思考设置；不支持零数据保留（ZDR）和 HIPAA，批处理接口暂不支持。Claude 自家平台、AWS、Microsoft Foundry、Google Cloud 都可用。

### Pi 1.5.0 发布：pi-schema 正式上线、流式输出提速、支持 GPT-6.1 Terra，附 5 个排障命令
*作者：小墨同学（@xiaomovps）· 11/02 20:05、21:31 北京时间*

距 1.4.0 十多天后，Pi（Mario 开发的开源编程 Agent 工具包）发布 1.5.0，五个要点：前两天公布的 pi-schema 正式替代 TypeBox 做工具参数校验（自动转换参数类型、无需 eval，普通插件基本兼容，用到 TypeBox 特殊校验的需注意）；大型 Tool Call 改为增量解析，终端代码高亮和 Markdown 渲染加缓存，降低 CPU 和内存；OpenAI、Azure、Codex 支持 GPT-6.1 Terra（Codex 提供 500K 上下文），OpenAI 默认模型从 GPT-5.5 改为 GPT-6.1 Sol；Tool Search 修好中文、日文等非 ASCII 分词；更新插件后启动时可直接看 Changelog。另修复 OpenCode Go、DeepSeek V4.1 Flash、Kimi K3.1 Pro 兼容性和 MCP OAuth 等问题。小墨同学还整理了官方排障方法：启动卡死先 `pi --no-extensions`；MCP 问题用 `pi mcp list`、`/mcp`、`pi --no-mcp`；认证用 `pi auth check --provider openai`（429 多半是限额不是登录问题）；`/session` 看上下文用量、`/compact` 压缩、`pi --continue` 恢复会话；终端异常用 `/debug` 生成 pi-debug.log、`/bug` 生成报告（分享前检查隐私）。

### 为什么一降温就容易感冒
*作者：Dr.Wang（@HotmailfromSH）· 11/02 14:17 北京时间*

低温本身不直接导致感冒，感冒由病毒引起（最常见是鼻病毒）。降温后更易中招的原因：天冷人们多待室内、少通风、近距离接触多，病毒更易传播；空气干燥影响呼吸道黏膜的水分和纤毛清除功能，低温低湿也利于部分病毒存活；吸入冷空气使鼻腔温度下降，可能削弱鼻腔局部抗病毒免疫。预防：勤洗手、多通风、人多处戴口罩、避免接触有症状的人，接种流感疫苗；保持规律睡眠、均衡饮食和适度运动；有症状尽量居家休息。
