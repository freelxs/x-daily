### Claude Code 团队如何做代码审查：自动审查后查出问题的 PR 比例从 16% 升到 54%
*作者：宝玉（@dotey）· 11/20 07:14 北京时间*

宝玉整理 Anthropic Claude Code 团队产品经理 Morgan Lunt 的分享：半年多前 Claude 写代码越来越快，等人审的改动排成长队，大家互相盖章，被称作“歌舞伎表演”。后来让 AI 智能体接手大部分审查，人只在高风险改动上签字，目标是 90% 的 PR 合并时除作者外无需别人审。结果：查出实质问题的 PR 比例从 16% 升到 54%，合并的 PR 数量翻倍，需回滚的 PR 少 40%。Lunt 认为这和自动驾驶一样，不必完美，比人强就够。
