Claude Code 省 Token 的 5 个开源项目：context-mode、RTK、claude-mem、Serena、caveman

作者：小墨同学（@xiaomovps）· 10/25 17:18 北京时间

作者整理了 5 个帮 Claude Code 等编程 Agent 节省 Token 的项目。context-mode 通过 MCP + Hooks 把冗长的工具输出放进沙箱过滤，只把需要的结果交给模型；RTK 是一个命令行代理，专门压缩 git、测试、构建等命令的输出，还能统计压缩效果；claude-mem 自动记录 Agent 的操作、决策和项目背景，下次开新会话时检索注入，少重复解释；Serena 通过 LSP 做符号级代码检索，直接定位函数、类和引用，避免反复读整个文件；caveman 则让 Agent 用"原始人"式的极简语言回复，减少冗余输出。作者建议新手先研究 context-mode、RTK 和 Serena，并提醒不要一次全装上，工具本身也有额外开销，省没省钱要看完整任务的 Token 和费用。

Matt Pocock：给 Agent 用的语言、可确定性自动合并的重构 PR

作者：Matt Pocock（@mattpocockuk）· 10/25 19:02、10/26 01:23 北京时间

医学科普：肠易激综合征（IBS）与"脑肠轴"

作者：Dr.Wang（@HotmailfromSH）· 10/25 17:46 北京时间

转载网易数读的科普：2026 年一项汇总中国 65 项研究、近 20 万人的荟萃分析估计，肠易激综合征合并患病率约 11%，常见表现是反复腹痛、腹胀，以及腹泻、便秘或两者交替。脑肠轴让压力和情绪会影响肠道，患者肠道感觉更敏感，但不能因此归咎于"心理脆弱"。诊断没有单项检查可确诊，按罗马 IV 标准需腹痛平均每周至少 1 天、近 3 个月符合症状且起病至少 6 个月。改善可从记录饮食、规律作息、适度运动和管理压力开始，可在专业指导下尝试低 FODMAP 饮食；出现便血、非刻意减重、贫血、夜间反复腹泻等警示症状应及时就医。
