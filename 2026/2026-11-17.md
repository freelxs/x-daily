### phonedriver：让 Claude Code / Codex / Cursor 直接操作安卓与 iPhone
*作者：GitHubDaily（@GitHub_Daily）· 11/16 08:18 北京时间*

phonedriver 是一个 MCP 服务和命令行工具，给 AI Agent 配一台“手机”：安卓、iPhone，模拟器和真机都行。它把每一屏读成带编号的文字清单，模型按编号点击，点完只回报界面变化，不必每步截图。作者拿 9 个手机任务对比，同样的活 mobile-mcp 的 token 用量是它的 6.9 倍。演示里 Claude Code 自己找门店、加购物车、填结账信息，到付款一步停下来询问人，最终没有下单。适合做 App 的人让 Agent 走一遍新用户首次打开流程找 Bug。

### Pi Agent 变身 Claude Code：One Code 扩展，以及 Pi 与 OMP 怎么选
*作者：xiaomovps（@xiaomovps）· 11/16 21:12、11/16 22:21 北京时间*

One Code 保留 Pi 的核心架构，用几十个 Extension 重新实现 Claude Code 的常用功能：Plan Mode、Auto Mode、Subagent、Git Worktree、权限管理，还能直接读取 CLAUDE.md、Skills、Hooks 和 MCP 配置。最大价值是把工作流与底层模型分开，例如主 Agent 用 GPT、Subagent 用 DeepSeek。已装 Pi 的话执行 `pi install npm:one-code-extension`；云端能力和系统级沙箱尚未实现。另一条帖给出选择建议：日常编程和大型项目选 OMP（内置 LSP、DAP 调试、Subagent、Worktree、浏览器操作）；想做 Personal Agent、自动化、自己控制插件与 token 的选 Pi；已深度使用 Pi 的老用户不必盲目迁移。

### 新款 MacBook Pro 双层 OLED 屏被反馈频闪、眼疲劳
*作者：lencx（@lencx_）· 11/16 15:11 北京时间*

帖子转述：新款 MacBook Pro 采用双层 OLED，HDR 峰值亮度从 Mini-LED 版 1,600 尼特提到 2,000 尼特，全屏持续亮度均为 1,000 尼特。有用户反馈眼疲劳、头痛、眩晕甚至退货。Notebookcheck 在亮度 99% 及以下测得 240 Hz、幅度 56% 的频闪（旧款 14 英寸 M4 Pro Mini-LED 为 14,880 Hz）。AppleInsider 称现有反馈不足以断定症状由 PWM 引起，部分 iPhone 与 OLED iPad mini 已有 Display Pulse Smoothing，Mac 暂无类似设置。
