### Barret李靖：Agent 时代的调试要从 Function Profiling 走向 Decision Profiling
*作者：Barret李靖（@Barret_China） · 11/08 21:50、11/08 22:55 北京时间*

推荐 DeepSeek Harness 的 **Context** 和 **Agent-Team** 两个插件：两者结合能看清 Agent 执行过程的全貌，信息呈现和交互都做得不错。他的观点：Agent as a Service 会成为常态，「太慢、效果差、太贵、同一任务每次路径不同」都需要被 Debug，关注点要从函数性能扩展到**决策**——好的调试器应能在某个决策节点暂停、改条件、Fork 出不同执行路径，再用 Replay 和 Evaluation 对比；对 Agent 系统则要从大量轨迹里找反复出现的低效决策、无效探索和失败模式，反推改进 Context 组织、工具设计和 Harness 架构。
另一条：每人一个能力约等于自己的数字分身（personal agent）并不意味着公司能完全由 AI 驱动，因为数字分身只能做本人能力的子集；企业数字员工应是「职能型」还是「角色型」？他目前的做法是用职能型沉淀专业能力、保障交付下限，再用角色型围绕业务目标组织能力、抬高端到端交付上限。

### Pi Durable 做个人 Agent：入门路线 4 个项目，以及会自己改自己的 Ultimate
*作者：小墨同学（@xiaomovps） · 11/08 14:16、11/08 22:01 北京时间*

小墨同学整理了从 Pi Durable（可持久化、崩溃可恢复的 Agent 运行时）入门做 Personal Agent 的学习路线：
1. pi-durable-hello：5 个小例子学任务持久化、崩溃恢复、请求去重和实时监听，不需要 API Key；
2. Batty：基于 Pi Durable 的私人 AI 助理 PWA，整合长期记忆、定时任务、Subagent、Skills、MCP，长期记忆设计最值得研究；
3. pi-durable-bot（Pots）：开源版「会主动干活」的 Bot，支持 Telegram / Slack / Discord，先用普通脚本检查任务、确认需要才调用大模型以省 Token；
4. Hearth Pi（ha-pi-durable）：把 Pi Durable 接进 Home Assistant，读设备状态，灯光/开关等操作需人工审批，仍属实验阶段。
后续一条介绍 **Ultimate**：本地 Coding Agent + Web UI，可通过改 Extensions / Skills / UI 代码给自己加功能（多数扩展支持热更新）；内置多 Agent 协作，用 Git Worktree 隔离、审查/测试/合并流程；靠 Pi Durable 保存状态，改完自身代码重启后能从持久化状态继续。

### Anthropic 工程博客：智能体记忆与「做梦」（dreaming）整理机制
*作者：宝玉（@dotey） · 11/08 11:21 北京时间*

11 月 6 日发文：Claude 跨会话记忆分四层（原始会话记录、自己写的笔记、整理出的 wiki 等结构、每次自动载入上下文的内容）；「做梦」是会话结束后回翻原始记录、纠正记错的笔记并重整的后台步骤。测试数据：数据库答题 Sonnet 4.6 有记忆 0.330→0.364，Opus 5 0.564→0.828；宝可梦红版 Sonnet 3.7 写 413 个记忆文件仅 1 枚徽章，Fable 5 只写 10 个文件拿 4 枚。经验：告诉 Claude 记忆是干什么的、别规定怎么记；自动加载层要小（Claude Code 自动记忆只载入 MEMORY.md 前 200 行或 25KB）；多 Agent 并行别写同一文件（共享表 57 条只留住 41 条，改成一份合同一页后 57 条全保住）。用 Stainless 约 35 万份文件做 wiki 测试：只靠 wiki 13%→48%，wiki+搜索 54%→61%。「做梦」已在 Claude Managed Agents 中作研究预览（需申请），记忆库为 beta，并放出 cookbook。数字均来自 Anthropic 自测。

### Anthropic 分析 20.7 万次科研会话：数据分析最多、提想法最少；科研产出最多可翻倍
*作者：宝玉（@dotey） · 11/08 12:18 北京时间*

11 月 4 日报告，样本为 2026-08-02 至 09-30 的约 20.7 万次科研相关会话。分析数据占 Claude 会话 33.7%（Claude Code 48.1%，科研时间占比约 28%）；写作沟通占科研时间 16%、会话 32%；收集数据占科研时间 28.6%、会话仅约 12%；提想法占科研时间 7.1%、会话 4.2%（Claude Code 仅 2.1%）。528 位科学家调研中，提想法重要性 35.6 分排第一。若现有 AI 能力普及，产出提升 1.35 倍（艺术）到 2.02 倍（统计），计算机 1.96 倍；AI 若包揽所有非动手步骤，计算机/统计等约 15～16 倍，生物化学材料仅 3～4 倍。专门的 Claude Science 会话中 73% 由 AI 高度自主完成（普通 Claude 24%）。三种加速情形是假设推算，非预测。
