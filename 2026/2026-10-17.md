### Claude Code 按任务分配模型：`claude --advisor opus --subagents haiku`

### Pi 1.3.0 发布：分享去向、缓存、换模型几处改进
*作者：小墨同学（@xiaomovps）· 10/16 08:09（北京时间）*

终端编程 agent Pi 发布 1.3.0，主要是补会话续用时的细节：① `/share` 新增 `sessionShareDestination`，可选 auto / gist / radius；② 用 API key 时会话中途改 GPT-6 的 thinking level 不再清空 prompt cache；③ kimi-coding 改走 `https://api.kimi.com/coding/v1`（Chat Completions），如果在 models.json 里覆盖了它的 base URL，现在必须带 `/v1`；④ 换模型时丢弃上一个模型的 thinking blocks，不再当正文传给新模型；⑤ resume 会恢复会话中途激活过的工具，`--tools +name / -name` 在此基础上加减；⑥ `openai-codex/gpt-6.1-sol` 的上下文从 272K 改回 500K。另外 `--model` 遇到多个 provider 同名模型时优先选有凭据的，并修了 Gemini 4 Argon、Xiaomi MiMo、Claude Haiku 5.5、Claude Opus 5 的 thinking level 兼容问题。

*作者：小墨同学（@xiaomovps）· 10/16 13:55（北京时间）*

### 管理 Pi 的三件套：Herdr、Collie、Executor
*作者：小墨同学（@xiaomovps）· 10/16 14:55（北京时间）*

Pi 本体故意做得很小，多 agent 管理、手机远程、账号连接都不在核心里，作者推荐三个外部工具补上（其他 agent 也能用）：**Herdr** 管多 agent 终端，每个 agent 一个面板，Pi 会上报 idle / working / blocked 状态，合上电脑任务继续跑，安装 `curl -fsSL https://herdr.dev/install.sh | sh`；**Collie** 是 Herdr 的手机端，自托管 PWA、MIT 开源，手机上能看哪个 agent 在等输入并直接回复，卡住会推送，安装 `curl -fsSL https://colliepwa.dev/install.sh | sh`，默认走 Tailscale，它本质是远程 shell，别直接暴露到公网；**Executor** 把 Gmail、GitHub、Slack 等账号统一接成一个 MCP 地址，凭证不进聊天和代码，官网有托管版，也能本地或 Docker 自部署（自部署免费）。

### magpie 新开关：精简 Claude 系统提示词，每次请求省约 1K token
*作者：yetone（@yetone）· 10/17 03:34；Geek（@geekbb）· 10/16 08:52（北京时间）*

magpie 是 yetone 做的菜单栏工具，能把各家订阅 / 模型接给不同 agent（例如 Codex 用 DeepSeek、Claude Code 用 Kimi）。以前它用真的 Claude Code 跑你的请求，每次都带着 Claude Code 自己约 1K token 的系统提示词。新版设置里加了「精简 Claude 系统提示词」开关（默认关），打开后用 `--system-prompt-file` 把你 agent 自己的指令换成系统提示词。实测（Sonnet 5.5 订阅）：每个请求固定省约 0.9–1.2K token；轻量聊天客户端 3 轮输入从 10,048 降到 6,580 token（−35%）；`claude -p` 这类自带大提示词的客户端 4 个请求从 85.4K 降到 81.9K（−4%）。作者提醒请求看起来没那么像 Claude Code 本身，账号风险自己权衡；这个功能"下个版本发布"。另外 magpie 已全面插件化，订阅 / Provider、网关中间件等都能用一个 npm 包扩展（geekbb 转发）。

Pi 官方（Earendil）发文介绍把 Pi 放进 Cloudflare Durable Objects：空闲时休眠，有 WebSocket 消息或闹钟到点才唤醒。一个 Pi 会话对应一个 Durable Object，数据存在它自带的 SQLite 里，打开同一个会话链接的人连到同一个对象，换个 ID 就完全隔离；会话里可以开多个对话、从某条消息分叉，多人同时聊。多人同时发消息时进 Pi 的持久收件箱按顺序回复，断线重连用同一个请求 ID 补发、不会重复执行；Durable Object 只有一个闹钟，所以每次醒来按最早的截止时间重设。存储可换（内存、JSONL、SQLite 或自己的后端）。作者提醒：Cloudflare 付费套餐要注意请求次数，超额会额外收费。
