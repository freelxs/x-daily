### Claude Code 省 Token 的 5 个开源项目：context-mode、RTK、claude-mem、Serena、caveman
*作者：小墨同学（@xiaomovps）· 10/25 17:18 北京时间*

作者整理了 5 个帮 Claude Code 等编程 Agent 节省 Token 的项目。context-mode 通过 MCP + Hooks 把冗长的工具输出放进沙箱过滤，只把需要的结果交给模型；RTK 是一个命令行代理，专门压缩 git、测试、构建等命令的输出，还能统计压缩效果；claude-mem 自动记录 Agent 的操作、决策和项目背景，下次开新会话时检索注入，少重复解释；Serena 通过 LSP 做符号级代码检索，直接定位函数、类和引用，避免反复读整个文件；caveman 则让 Agent 用"原始人"式的极简语言回复，减少冗余输出。作者建议新手先研究 context-mode、RTK 和 Serena，并提醒不要一次全装上，工具本身也有额外开销，省没省钱要看完整任务的 Token 和费用。

### DeepSeek Harness 可搭配的 4 个模型渠道对比，以及和 WorkBuddy 的实测
*作者：小墨同学（@xiaomovps）· 10/25 15:52、19:07 北京时间*

作者对比了给 DeepSeek Harness（DSH）供模型的 4 个渠道。DeepSeek 官方 API 最省心，DSH 原生支持，按 Token 计费，原帖给出 V4.1 Flash 非高峰输入 $0.15/百万、输出 $0.60/百万；OpenCode Go 每月 $10，DeepSeek V4.1 Flash 有 $80 的月度用量上限，但有 5 小时、每周、每月额度限制，社区反馈最近变慢，DSH 里还要注意 Session Header 兼容问题；OpenRouter 推理厂商最多、可按速度和价格路由，适合按量或作备用线路；Command Code 的 GOAT 套餐同为每月 $10，官网标注 DeepSeek V4.1 Flash $80 用量，DSH 靠社区插件接入。作者提醒"$80"是模型使用限额，不是送官方余额。另一帖里他用同一个"鹈鹕骑自行车"HTML 提示词对比腾讯 WorkBuddy 和 DSH：前者约 90–110 万 Token、运行 4 分多钟，后者约 120 万 Token，两边缓存命中率都接近 99%，但他觉得 DSH 的画面细节和配色更好，并强调这只是单一提示词的小测试。

### x-reader：会如实交代"读到了什么"的 Agent 内容读取工具

### Matt Pocock：给 Agent 用的语言、可确定性自动合并的重构 PR
*作者：Matt Pocock（@mattpocockuk）· 10/25 19:02、10/26 01:23 北京时间*

Matt Pocock 认为下一门伟大的"Agent 语言"应该像 Rust 一样快、像 Go 一样设计空间小，并拥有史上最严格的类型/验证系统，Bend 是个有意思的早期尝试，但他用三四个提示词就把 Bend 的在线 playground 弄崩了，认为还远没准备好。他还设想一种工具：在极严格的约束下（只重组代码、不改变模块图、不降低测试覆盖率等）确定性地判断一个 PR 能否自动合并，让重构更放心；随后又补充，理想情况是重构源代码而打包产物不变，但这要求不用 `import.meta.glob`、不读运行时文件位置、没有全局状态，"想得越多越觉得可能做不到"。另外他介绍新课程最后一节会在 GitHub Actions 上搭一个基础"软件工厂"。

### 小墨同学的 Grok Bot 使用心得：三个坑、定期清理记忆、手机全链路开发
*作者：小墨同学（@xiaomovps）· 10/25 10:13、11:28、13:34、20:06、22:15 北京时间*

小墨同学当天连发多帖。三个坑：一是云电脑可能回滚到旧快照，他建议用一个私有 GitHub 仓库定期备份记忆、Skills、项目配置和素材（别提交 API Key、Cookie 等凭据）；二是同一账号下的多个 bot 共用一台云电脑，文件、浏览器登录和命令行凭据都是共享的，建议分目录、最小化 GitHub 权限；三是定时任务可能延迟或漏跑，建议定期查看运行历史、记录上次成功时间。他还建议每半个月到一个月做一次"记忆大扫除"，清理重复、冲突、过时的记忆、人设和 Skills，并认为模型路由不透明（这部分他明确说是个人猜测）。工作流方面，他用手机给 Grok Bot 下任务、调用 Cursor 云端开发测试、再走 GitHub PR 和 CI/CD；订阅方面只保留 Claude Pro（$20/月）和 Grok 整合订阅（$100/月），取消了 GPT。省额度玩法：在云电脑里装 Pi Agent 接 OpenRouter 免费模型处理简单任务，原帖称在 OpenRouter 充值 $10 后免费模型请求上限从每天 50 次提高到 1000 次、每分钟 20 次。
