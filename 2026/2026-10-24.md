*作者：宝玉（@dotey）· 10/24 01:51 北京时间；yetone（@yetone）· 10/24 02:03 北京时间；钟星宇（@zhongxingyuyes，转推）· 10/24 01:39 北京时间；lencx（@lencx_）· 10/23 12:50 北京时间*

月之暗面 10 月 23 日发布 Kimi K3.1 Pro，Kimi 网页版和 App、办公助手 Kimi Work、编程工具 Kimi Code 和 API 当天上线，官方称完整权重 11 月 4 日前放出（许可证条款尚未公布）。它在 K3 基础上继续训练、结构不变，主要多花算力做强化学习；总参数 2.8 万亿、每个 token 激活约 1040 亿（MoE 混合专家），上下文 100 万 token，支持图片和视频。宝玉整理的官方对比（部分对手成绩是 Kimi 自测）：Terminal-Bench 4.0 得 65.7%（Opus 5.5 66.4%、GPT-6 Astra 58.2%），SWE-Marathon 51.7 排第一，BenchCAD 92.7% 略逊，OfficeQA Pro v2 64.4 排第一；"幻觉降低 65%"来自内部难题事实核查测试（每 100 个事实错 23 个降到 8 个出头）。

### Pi 与 DeepSeek Harness（DSH）生态：AOT 编译版 Pi-Bolt、Rust 重写 pi-rs、pi2dsh 兼容层与必装插件
*作者：小莫（@xiaomovps）· 10/23 08:40–22:45 北京时间（7 条）；Kevin（@kevinzhow）· 10/23 21:31 北京时间*

小莫这一天集中写了开源编程 Agent Pi 和 DeepSeek Harness 的生态：**Pi-Bolt** 用 AOT 把 Pi 编译成单个原生可执行文件，作者在 Linux 上测得启动 45ms（原版 Pi on Bun 382ms）、交互 CPU 开销降约 6 倍，原有 Session、配置和大部分扩展可继续用；**pi-rs** 用 Rust 重写了模型接入、TUI、工具、Session 和 RPC，并内嵌 Boa JS 引擎运行原 TS 扩展，兼容性仍在完善。**pi2dsh** 让 Pi 插件通过 Host API 跑在 DSH 里，但目前只有十几款插件实测通过。

他推荐的 5 个 Pi 插件：pi-subagents（多 Agent 协作）、pi-web-access（联网搜索、抓 URL、读 PDF 和 YouTube）、pi-mcp-adapter（按需启动 MCP 服务器）、Plannotator（在浏览器里批注和审批 Agent 计划与 Diff）、pi-lens（LSP、Lint、类型检查回馈）。对比两者：Pi 核心精简、终端优先、官网 Package Catalog 已收录 5000 多个包但缺内置市场；DSH 预置 Plan/Todo/子任务，带 Web UI，社区做了 dshmarket 插件市场，但他吐槽 DSH 工具调用过多、一个任务来回 28 轮、出错缺少可靠的验证。Kevin 则评价"DSH 能发挥出 DeepSeek 最大的潜力，超出预期"。

### 医药科普：神经痛为什么会开抗癫痫药或抗抑郁药
*作者：HotmailfromSH（@HotmailfromSH）· 10/23 19:25、19:38 北京时间*
