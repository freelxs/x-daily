### Rex / Pi 支持终端新协议 OSC 7577，重启后可恢复 Agent 会话
*作者：小墨同学（@xiaomovps）；Mitchell Hashimoto（@mitchellh）· 11/26 16:29 北京时间*

Mitchell Hashimoto 发布新终端协议 Program Resume Protocol（OSC 7577）：让程序主动告诉终端“重启后该执行哪条命令”来恢复自己，Rex 已支持（内置对 Claude Code 的支持）。小墨同学整理：Pi 已合并该协议，会上报类似 `pi --session <id>` 的恢复命令，正常退出（Ctrl+D 或 `/quit`）会清掉，意外关闭则保留；每个终端面板用随机 Token + SHA-256 校验防注入，Pi 启动后会删除 `OSC7577_TOKEN` 环境变量；恢复只是提示，由终端决定是否执行。目前尚无正式版本，最新正式版仍是 1.6.1。此外 Mitchell 称 Rex 已在 App Store 上架，但需要另一台设备上运行 Rex Server，暗示公开发布临近。
