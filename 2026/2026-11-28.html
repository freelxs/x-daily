作者：小墨同学（@xiaomovps）；佐仔（@huangjinbo）；Geek（@geekbb）· 11/27 09:44–22:26 北京时间

小墨同学把市面上功能重叠的 AGY 增强插件筛了一遍，认为全装容易把客户端自动更新搞坏，留下 5 个不太打架的就够：agy-fast 把批量搜索、大纲提取、多文件修改和跑测试收成 5 个本地 MCP 工具，项目实测约少 34% 轮次、省 31% 额度，CLI 与 2.0 桌面端都能用；Ponytail 强迫 Agent 复用已有代码，官方在 Claude Code 里测得代码量少 53%、Token 省 45%，AGY CLI 可跑完整命令、桌面端当规则集挂载；agy-powertools 给 2.0 桌面端加上下文占用、缓存命中、吐字速度和本地用量看板，并带会话分支、原位改消息和简体中文，走本地只读挂载、不改安装文件；Paragravity 用官方数据目录沙箱给多账号开独立窗口，但生成的配置目录里有明文登录凭据，不要同步到云盘；antigravity2-cn 是纯汉化包，若已装 powertools 则不必再装，而且 Mac 上打底层补丁会触发重新签名，可能导致官方自动更新校验失败。他的日常组合就是 agy-fast + agy-powertools。huangjinbo 也大力推荐 agy-powertools（中文界面、用量统计、会话分支、多账号切换、免 TUN 代理、SSH 与 WSL2）。geekbb 另外汇总了用量监控、多语言包、切号和换肤等仓库，并提醒：这类非官方插件（哪怕只是汉化）是否被官方允许、有没有封号风险并不清楚，他自己目前只用其中一个的主题、汉化和用量监控。

Anthropic 把核心 Messages API 从 Python 重写成 Rust：关键是验证 Harness

作者：小墨同学（@xiaomovps）· 11/27 16:09 北京时间

Anthropic 发布工程复盘：Messages API 在 2023 年是 Python 转发器，线上请求约两年多暴涨 1800 倍；今年 3 月只把解析输出改成 Rust，CPU 只省不到 10%，还增加跨语言边界。5 月团队发现内部合入代码超过 80% 已是 Claude 所写，决定整套重写。Claude 约一周写出 Rust 初版，700 多个旧集成测试通过率达 98%，但与线上真实流量比对，输入匹配率只有约四分之一；工程师还在 AI 迁过来的测试里抓到 100 多处被放水的断言。后来的办法是让同一份模型输出同时跑新老两套代码，用字节位置和长度差做「指纹」归类再交给子 Agent 修，并加沙盒与记忆循环，把打回的教训写入 CLAUDE.md。9 月切流上线后，单请求 CPU 约降 70%，首字延迟约降 20%。作者的结论：现在拉开差距的不是写代码有多快，而是能不能搭一套严密的验证 Harness，并在关键架构上由人把关。以上数字来自官方复盘与原帖转述。

1）Coucou（约 7,500 Star）：在 Mac 刘海屏盯多个编程 Agent（Claude Code、Codex、Cursor、Antigravity、Hermes 等），可看改了哪行代码以及 5 小时/每周剩余额度，权限弹窗能直接批；离开电脑后经私有 iCloud 同步到 iPhone 灵动岛和锁屏，用面容 ID 远程审批，并内置本地离线语音输入。完整多 Agent 支持需用 GitHub 安装包，商店沙盒版有限制。2）last30days-skill（约 7.5 万 Star）：同时检索 Reddit、Hacker News、X、YouTube 字幕、GitHub、arXiv 和预测市场等，按真实互动量打分过滤 SEO 水文；安装：npx skills add mvanhorn/last30days-skill -g，需 Python 3.12 以上，Reddit 和 HN 免配置，抓 X 等平台要自备接口或登录态。3）llm.asm：约 1.7 万行纯 x86-64 汇编写出推理引擎和约 24KB 可引导内核，无 C/Rust/系统依赖，在无硬盘的 Proxmox/KVM 上不到 100 毫秒可启动并与 Qwen3-0.6B 对话；目前没有网卡驱动，长提示词预填充仍不如 llama.cpp，偏硬核演示。4）AgenticAlgorithmEngineering：海德堡大学算法工程组的插件，强制 Agent 先做性能剖析、提出可证伪假设、跑过基准和断言才保留补丁；若要自动出完整实验报告，需本地准备 Python 3 和 LaTeX。5）minipg：不用 Docker，单个可执行文件约 800 毫秒拉起 PostgreSQL 18，数据落在便携的 .pgdb 文件夹里，适合给 Agent 搭临时测试库，作者也提醒仍是早期原型，别上生产。
