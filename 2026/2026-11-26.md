### Claude 为 MCP 新增三项能力：Skills over MCP、Tasks、Elicitation
*作者：宝玉（@dotey）· 11/25 10:49 北京时间*

据宝玉解读：①Skills over MCP：Skills 可以与 MCP 一起发布，避免 MCP 工具说明已更新而 Skills 仍是旧版本的版本不一致问题；②Tasks：把耗时长的任务改为异步后台执行，Agent 不必等待结果，可先做别的事，完成后再继续；③Elicitation：在敏感操作前增加确认环节，例如删除 GitHub 仓库时不仅要点确认，还要完整输入仓库名，防止 Agent 误操作。

### xnulinux：把 macOS 的 XNU 内核作为模块塞进 Linux
*作者：GitHub_Daily（@GitHub_Daily）；少数派 appinn（@appinn）· 11/25 08:00、15:07 北京时间*

xnulinux 把苹果开源的 macOS 内核 XNU 编译成 Linux 内核模块，加载后可启动完整 macOS 桌面，访达、程序坞、Safari、Chrome 可用，macOS 与 Linux 程序在同一颗 CPU 上并排运行，没有虚拟机层。作者在 Apple 芯片 Mac 的 Linux 虚拟机中测试，开机到桌面 31–48 秒（苹果自家虚拟机约 49 秒），连续 30 分钟反复开关应用无崩溃，也能在 NVIDIA DGX Spark 这类 ARM 机器上启动。仓库不含任何苹果系统文件，需用自己的 macOS 安装制作系统盘。
