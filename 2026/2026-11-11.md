### Gemini 4 Carbon 正式开放：付费 API 今天可用，引入价到 11 月 30 日，普通用户需订 Ultra
*作者：宝玉（@dotey） · 11/11 00:28 北京时间*

Google 11 月 10 日把 Gemini 4 Carbon 开放给付费开发者、企业和 Google AI Ultra 订阅用户（10 月 28 日首次亮相时仅限通过审查的网络安全防御团队）。普通用户需订 Ultra：每月 99.99 美元（用量为 Pro 的 5 倍）或 199.99 美元（20 倍），每月 19.99 美元的 Pro 用不了；开发者走 Gemini API 付费层，模型名 `gemini-4-carbon`，免费层没有。价格与 Argon 相同：11 月 30 日前引入价每百万 Token 输入 2 美元、输出 10 美元，12 月 1 日起翻倍为 4 / 20 美元。按原帖的说法，Carbon 每轮思考用的 Token 比 Argon 多、响应更慢，同一任务可能更贵；涨价后单价与 Claude Opus 5.5 持平，是 Fable 5.2 的一半。

评测方面（多数为 Google 或 Anthropic 自己公布）：Google 的 375 题诚实度测试 Carbon 通过 92%（Argon 70%）；Artificial Analysis 综合榜上 Fable 5.2 65 分、Carbon 60 分、Opus 5.5 59 分、GPT-6 Astra 57 分；Zapier 的 AutomationBench 上 Carbon 53.9%、每任务 2.12 美元，Fable 5.2 51.5%、4.64 美元。Antigravity 还预览了 `/swarm` 命令：一句话拉起一队有分工的 agent，配验证员并共享留言板，Pro 和 Ultra 都能用，但每个 agent 单独耗额度。

### 软件正在从“给人用”变成“给 Agent 用”：宝玉的两则思考
*作者：宝玉（@dotey） · 11/11 03:29、07:54 北京时间*

宝玉认为软件开发的瓶颈已不是做出专业软件，而是三件事：让 Agent 更好地用你的软件（Agent 最友好的方式是 CLI、MCP 和代码，而不是 GUI）；让人更好地预览和微调（人只需检查结果、标记评论，所以视频编辑器不必再做复杂 Timeline）；满足个性化长尾需求（人人都在用 Agent 做自己的软件，未来软件能力会原子化为一个个 CLI 命令和 MCP 调用）。最后一个思考题是：人人都能做软件时怎么把软件卖出去，他自己也没有答案。清晨他进一步总结：Google Docs 颠覆本地 Office 是从“单机”变“云端”，Claude Artifacts 代表的是软件从“给人用”变成“给 Agent 用、人审查微调”。

### Pi 1.5.1 更新要点与“从 Claude Code 转向 Pi”的讨论
*作者：小莫（@xiaomovps） · 11/10 08:12 – 11/11 04:14 北京时间*

Pi 1.5.1 主要是日常体验打磨：可直接在终端 `pi auth login <provider>` / `pi auth logout <provider>`（支持 `--api-key`、`--no-browser`）；Prompt Cache 保温默认从 streaming 改为 idle，最多空闲保温 30 分钟，会先判断划不划算，可在 `~/.pi/agent/settings.json` 里设 `"cacheWarming": "streaming"` 或 `"off"`；Anthropic 官方 API 默认启用 Message Threads，只发新增消息；多家默认模型更新（Anthropic 为 Claude Opus 5.5 等）；1.5.0 起默认全屏终端，想恢复旧样式用 `pi --tui-mode regular`。

他另外评论了 HN 热议文章《Goodbye Claude, Hello Pi》：作者统计到今年 9 月 Claude Code 已发 244 个版本、超 75% 改过 System Prompt 或工具描述，换成 Pi 后 20 分钟就用扩展解决了多会话问题；反方认为 Pi 缺少默认安全审批。他还引用 TokenSave 数据称 Claude Code 初始输入 Token 从 2026 年 5 月的 36,309 降到 10 月的 18,841，并称 Anthropic 为新模型精简了 80% 以上系统提示词而评测没有明显下降，认为极简 Agent 更有前景。
