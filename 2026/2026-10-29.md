### Google 发布 Gemini 4 Carbon：Artificial Analysis 综合榜第一，本周只开放给网络安全防御方
*作者：宝玉（@dotey）· 10/29 02:18 北京时间；morluto（@morluto）· 10/29 01:48；Xuanwo（@xuanwo）· 10/29 01:18*

Google 10 月 28 日发布 Gemini 4 Carbon，距上一代 Gemini 4 Argon 只隔两周；在 Artificial Analysis 综合榜（v5.0）上得 59 分排第一，比 Claude Opus 5.5 高 1 分、比 GPT-6 Astra 高 2 分。Google 公布的 17 项对比里 Carbon 拿下 15 项第一，没赢的是编程 FrontierSWE 2（GPT-6 Astra 65.5% 对 61.2%）和电脑操作 OSWorld（Opus 5.5 87.2% 对 81.5%）。安全方向很突出：SEC-bench Pro 找漏洞 88.2%、ExploitGym 验证可利用性 54.8%、CWE-bench 修漏洞 71.0%，这些分数是关掉安全防护后测的。因此本周只给经过审查的网络安全防御团队（Fairwind 计划），开发者和普通用户开放时间未定。API 价格与 Argon 相同：引入期每百万 token 输入 2 美元、输出 10 美元，之后涨到 4 / 20 美元。morluto 借此感叹百度曾差点请到 Hinton、Ilya 等人，如今在模型训练上却明显落后。

### GitHub Universe：Copilot Fusion 自动挑模型，新代码审查 Max 档平均每次约 10 美元
*作者：宝玉（@dotey）· 10/29 02:35 北京时间；Matt Pocock（@mattpocockuk）· 10/29 00:14*

GitHub 10 月 28 日在年度大会 Universe 上发布 Copilot Fusion：按任务难度自动安排模型，简单活一个模型做，难的先让便宜模型起草、不过关再换强模型，最难的让多个模型同时挑错。Fusion 已在 VS Code、JetBrains、命令行和桌面应用上线，所有套餐（含免费版）有基础档，High / Max 档需 39 美元/月的 Pro+ 及以上；计费按「AI 点数」（1 点 = 1 美分，Pro 每月送 1500 点），11 月 30 日前付费用户七折。代码审查新增 Max 档（公测，Pro 及以上），多家模型各审一遍再汇总，官方估算平均每次约 10 美元、最多 25 美元；Copilot 还能正式批准 PR（默认关闭），并新增「Watch and fix」按钮自动修 CI 失败和冲突。宝玉的评价是 Copilot 整体体验仍比 Claude Code 和 Codex 差一个量级。另外 Matt Pocock 发现自己的 /drill-me skill 被主题演讲点名。

### Tw93 的 20 条 AI Coding 最佳实践
*作者：Tw93（@HiTw93）· 10/28 16:52 北京时间*

Tw93 把自己的 AI 编程经验整理成 20 条规则，分需求、规则、编码、排查、审查、发布、复盘七组。要点包括：多讲背景和目标、少替 Agent 想技术细节；用最好的模型；新功能和新开关先让 Agent 问你；每次只做最小可用版本。必须遵守的规则不要只靠 prompt，要用脚本拦；让 Agent 补一个自我验证脚本；多 Agent 并行各用独立 worktree。修 Bug 两次不行就加日志看真实数据，三次不行就清空上下文重来；写代码和审代码的 Agent 分开，Review 最多跑 3 轮；删除、付费、发布这类「单向门」改动要自己亲手验证；每个线上 Bug 都留一个测试用例，换模型时整体回归。

### 让 Agent 自己清理 worktree；Claude Code 建议设 /autocompact 300k
*作者：宝玉（@dotey）· 10/28 13:28、10/29 02:08 北京时间*

有人反馈 Claude Code / Codex 每个 Agent 会话都开独立 git worktree，41 个没清理的 worktree 占了 45GB。宝玉的做法是在 AGENTS.md 里写规则：任务完成时必须删除 worktree 及其分支和专用构建目录；不合并就先提交并打 `archive/<worktree 名>` tag 再删，确需保留的要在回复里点名说明。另一条建议：Claude Code 的 1M 上下文模型默认到约 967K token 才自动压缩，期间每次请求都带上全部历史、持续消耗额度；运行 `/autocompact 300k` 把阈值提前到 300K（原推建议 400K）可以大幅节省长对话的 token。
