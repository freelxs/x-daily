### OpenAI 发布 GPT-6.2 Astra 与 Sol，Astra API 降价 20%
*作者：宝玉（@dotey）；Tibo（@thsottiaux）· 11/18 02:09–02:16 北京时间*

OpenAI 于 11 月 17 日发布 GPT-6.2 的两款模型：Astra 是旗舰，Sol 是日常主力。Plus 及以上订阅（Pro、企业版、教育版，帮助文档里还有 Business）从当天起可在 ChatGPT Work 和 Codex 里选用，普通聊天界面里没有；企业版和教育版需管理员先开启。按 OpenAI 文档估算，Plus 用户每 5 小时大约能给 Astra 发 6–50 条消息、Sol 17–180 条。API 价格：Astra 每百万 Token 输入 8 美元、输出 40 美元（比 GPT-6 Astra 的 10/50 美元便宜 20%），缓存命中输入 0.4 美元；Sol 维持 2/10 美元。OpenAI 主打"同样的活用更少 Token"，Ultrafast 模式生成速度最高为标准的 4.5 倍、消耗 6 倍额度，Pro 200 美元档目前只能在 Sol 上开 Ultrafast。Tibo 称 Sol 是他日常最常用的模型。

### Floorplan：让 Claude Code / Codex 把整个代码库画成可点开的应用地图
*作者：GitHubDaily（@GitHub_Daily）· 11/17 15:30 北京时间*

Floorplan 让 Claude Code 或 Codex 读完整个代码库，画成一张可缩放、可点开的应用地图，每个模块、文件、接口都配一句大白话说明（如不写"Stripe API 封装"而写"结账时收银行卡付款"）。前端每个请求打到哪段服务端代码都有连线，分开的多个仓库也能串起来；可对着地图提问，并附带专查 AI 应用常见问题的"体检"（密钥写进代码、数据库表任何人可读、接口不登录就能调等），每条给出可粘贴的修复；AI 改完代码后动过的模块会亮绿色并写明原因。

### HiTw93：吉隆坡见闻——和想象不一样的几件事
