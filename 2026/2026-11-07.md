### libghostty 1.0：ABI 稳定，邀请发行版打包
*作者：Mitchell Hashimoto（@mitchellh）· 11/07 07:29 北京时间*

Mitchell 宣布 libghostty 1.0：Ghostty 项目约 5 年前启动，如今 libghostty 已进入数百个项目、服务数千万用户。1.0 标志 ABI 稳定与质量门槛，并正式邀请发行版开始打包。他用一张影响图回答「为什么做 Ghostty」：除 JetBrains、Neovim（合计超千万用户）外，KDE 在试基于它的 Konsole 替代；Vercel Turborepo 用它渲染 TUI 任务输出；devenv、Antithesis、Ghostel（Emacs）、ghostty-web（WASM + Xterm.js 兼容 API）、OrbStack 等商业/开源产品都在用；新终端与 agentic 编程工具如 herdr、cmux 直接建在 libghostty 上。社区有 Rust / Go / JS / Swift / Python / .NET / Elixir / Dart / Java 等绑定，awesome-libghostty 跟踪一百多个项目。他强调：今天用 libghostty 驱动的终端用户，远多于 Ghostty 应用本身。
