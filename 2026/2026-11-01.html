Ubuntu LXD 曝出满分 10.0 漏洞（CVE-2026-112816）：伪造证书链即可接管整个集群

作者：小众软件（@appinn）· 10/31 13:32 北京时间

Canonical 10 月 30 日披露 CVE-2026-112816，CVSS 4.0 评分 10.0。LXD 远程管理本应靠客户端证书认证，但证书验证有缺陷：攻击者只要拿到某个受信任客户端的公开证书，就可能伪造证书链绕过认证，不需要密码也不需要私钥，拿下整个 LXD 集群的管理权，进而控制容器、虚拟机，甚至拿到宿主机 root。受影响的是用 LXD 或 MicroCloud 管服务器 / 私有云的用户；普通 Ubuntu 桌面用户、只用 Docker 或 Proxmox VE 自带 LXC 的用户不受影响。修复版本（10 月 29 日发布）：LXD 6.10.1、5.21.9（LTS）、5.0.11（LTS）、4.0.15（LTS），MicroCloud 3.4.1、2.1.5。Snap 安装的执行 sudo snap refresh lxd，MicroCloud 执行 sudo snap refresh microcloud。

Linux 内核高危漏洞 CVE-2026-98432（9.8 分）：Go 写的网络服务首当其冲，Xray-core 发布紧急更新

作者：Geek（@geekbb）· 10/31 21:43 北京时间

Linux 内核新曝 CVE-2026-98432，CVSS 9.8，是 IPv4 TCP 的释放后使用（use-after-free）漏洞，已有远程拿到 root 的 PoC。原帖指出，Go 1.24 及以上版本默认给 TCP 监听开启 MPTCP，所以用 Go 写的服务端程序（原帖举例 Xray、Caddy 等）首当其冲。开源网络工具 Xray-core 发布紧急版本，直接把 MPTCP 默认关闭以缩小攻击面；此前的 v26.10.29 已撤版，GitHub 上最新版本是 v26.10.31（10/31 21:37 北京时间发布）。在服务器上跑 Go 程序的，除了升级应用，也建议关注发行版的内核补丁。

agent-desktop：Vercel Labs 开源的桌面版「agent-browser」，靠无障碍树操作任意应用

作者：lencx（@lencx_）· 10/31 12:30 北京时间

agent-desktop 给现有编程 Agent 提供 Computer Use 能力，支持 macOS、Windows、Linux。它不靠截图识别，而是读取操作系统的无障碍树，把按钮、输入框、菜单转成带稳定引用的结构化 JSON，让 Agent 走「观察—操作—验证」循环；支持的操作默认走无障碍 API 在后台执行，不抢鼠标和前台焦点。多个 Agent 可共享同一桌面，各自显示独立光标，并用跨进程锁避免输入交错。用 Rust 编写，提供 CLI、配套 Skill 和 C ABI 原生库，可从 Python、Swift、Go 调用；覆盖范围取决于应用暴露的无障碍信息。

作者：Dr.Wang（@HotmailfromSH）· 10/31 09:16 北京时间

转述网易数读：一项 2026 年发表的中国多中心研究分析近 2 万名成年人，维生素 D 缺乏率 29.89%，女性 39.95%、男性 20.02%，40 岁以下 33.46%。原因不能简单归为运动少或防晒，日照、饮食、年龄、体重、环境都有影响。补充途径：三文鱼、沙丁鱼、蛋黄、强化食品；适度日照但不要刻意暴晒；补充剂不是越多越好，长期大剂量可能导致高钙血症、损伤肾脏。长期缺日照或有骨质疏松风险的，可以咨询医生检测血液 25-羟基维生素 D。
